Assumptions and how this works

The same Python analysis used in the full explorer computes eight synthetic summaries. This page embeds those summaries; target changes are calculated in your browser without server round trips.

Time = original usable time × (p95 / target)². This assumes independent, stationary epochs; real drift and artifact loss can invalidate it. Time is usable data, not total acquisition time.

N = ceiling[(1.960 + 0.842)² × (paired SD / target)²], for 80% power and two-sided α = .05. This normal approximation can be optimistic at small N. It holds SD and recording duration fixed; it does not inherit the time projection.

Real planning needs a scientifically justified target and independently estimated, state-, protocol-, and duration-matched variance. Internal split halves are not independent test–retest validation. The p95 is a descriptive benchmark, not a clinical decision threshold.

Alpha/delta ratio changes use log10 units; 0.301 means a two-fold ratio. Relative theta is displayed in percentage points. Both are simulated marker values, not measured EEG here.
